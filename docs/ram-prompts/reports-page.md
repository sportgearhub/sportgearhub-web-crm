# Reports Page RAM Prompt

## Route
`/reports`

## Purpose
Show lightweight provider performance analytics and placeholders for future reporting features.

## Current Layout
- Header with prototype badge and disabled export button
- KPI metric grid
- Two report cards
- One advanced analytics placeholder card

## KPI Metrics
- Total bookings
- Completed bookings
- Revenue from confirmed/completed bookings
- Catalog readiness

## Report Cards
### Bookings by Status
- Horizontal progress-style bars by booking status
- Shows count and percentage feel

### Top Offers
- Ranked list of sample top offers
- Shows booking count and revenue

## Advanced Analytics Placeholder
- Informational text only
- Notes future availability of richer analytics API features

## Current Data Source
- Local mock stats and bookings

## UX Character
- Lightweight reporting overview
- Not yet a fully dense analytics workspace
